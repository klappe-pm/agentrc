# install

This page covers installing agentrc: `pipx install agentrc` once the first release is published, `pipx install git+https://github.com/klappe-pm/agentrc` in the meantime, an editable install for contributors, the supported Python versions, and upgrading and uninstalling. Once the engine is extracted it will also describe installing the git hooks and verifying that each runtime's target directory is writable.
