# how-to-guides

How-to guides are recipes. Each one solves a specific problem for a reader who already knows what agentrc is and wants the steps, with the minimum of explanation along the way. They assume more than a tutorial and promise less: a guide gets you to one outcome, and links to the reference pages for the details it skips.

## pages

- [install](install.md): every supported way to install, upgrade and uninstall the command.
- [migrate existing config](migrate-existing-config.md): bring a hand-maintained runtime directory under one source root without losing local changes.
- [troubleshooting](troubleshooting.md): known failure modes matched to their fixes.
