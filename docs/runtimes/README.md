# README.md

The agent runtimes agentrc targets, with the default directory it deploys each one to. Each will get its own page describing the files agentrc writes for it once the engine is extracted.

- Claude Code: `~/.claude/`
- Codex: `~/.codex/`
- Gemini CLI: `~/.gemini/`
- Cursor: `~/.cursor/`
- OpenCode: `~/.config/opencode/`
