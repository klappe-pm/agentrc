# opencode

This page is the reference for what agentrc writes into the OpenCode target, `~/.config/opencode/` by default: the instruction file, the configuration that registers plugins and permissions, and how rules, skills, commands and agents are translated. For each output it will name the source it is built from and the format OpenCode expects. The table fills in as the OpenCode adapter is extracted.

## target

`runtimes.opencode.target` in `agentrc.toml`, default `~/.config/opencode`. Disabled by default.

## outputs

Documented as the adapter lands.
