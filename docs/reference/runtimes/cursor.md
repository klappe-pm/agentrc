# cursor

This page is the reference for what stratarc writes into the Cursor target, `~/.cursor/` by default: the rules directory, the instruction file and the hook and permission settings Cursor can read. For each output it will name the source it is built from and the format Cursor expects. The table fills in as the Cursor adapter is extracted.

## target

`runtimes.cursor.target` in `stratarc.toml`, default `~/.cursor`. Disabled by default.

## outputs

Documented as the adapter lands.
