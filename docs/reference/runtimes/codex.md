# codex

This page is the reference for what agentrc writes into the Codex target, `~/.codex/` by default: the instruction file, the configuration that carries the approval policy and sandbox settings, and how rules, skills and hooks are translated where Codex has an equivalent. For each output it will name the source it is built from and the format Codex expects. The table fills in as the Codex adapter is extracted.

## target

`runtimes.codex.target` in `agentrc.toml`, default `~/.codex`. Disabled by default.

## outputs

Documented as the adapter lands.
