# gemini

This page is the reference for what stratarc writes into the Gemini CLI target, `~/.gemini/` by default: the instruction file, the settings file that carries hooks and tool permissions, and how rules, skills and commands are translated. For each output it will name the source it is built from and the format Gemini CLI expects. The table fills in as the Gemini CLI adapter is extracted.

## target

`runtimes.gemini.target` in `stratarc.toml`, default `~/.gemini`. Disabled by default.

## outputs

Documented as the adapter lands.
