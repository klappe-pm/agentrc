# claude

This page is the reference for what stratarc writes into the Claude Code target, `~/.claude/` by default: the instruction file, the rules directory, hook registrations in the settings file, skills, commands, agents and the permission lists. For each output it will name the source it is built from and the format Claude Code expects. The table fills in as the Claude Code adapter is extracted.

## target

`runtimes.claude.target` in `stratarc.toml`, default `~/.claude`. Claude Code is the one runtime `stratarc init` enables by default.

## outputs

Documented as the adapter lands.
