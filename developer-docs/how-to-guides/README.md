# how-to-guides

How-to guides are recipes for a development goal. Each one assumes you have the repository set up and know your way around it, and gives the steps for one task with the minimum of explanation. They link to the reference pages for the details they skip and to the explanation pages for the reasons behind them.

## pages

- [add a runtime](add-a-runtime.md): write an adapter for another agent runtime, register it and test its output.
- [run the tests](run-the-tests.md): the test suite, its markers, and the lint and scan checks CI runs.
- [cut a release](cut-a-release.md): bump the version, settle the changelog, tag and publish.
