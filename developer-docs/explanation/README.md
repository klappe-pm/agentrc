# explanation

Explanation pages give the reasoning behind the code: how the pipeline is shaped and why, what was decided and what was rejected. They are for a contributor who wants to understand agentrc before changing it, and they are the right place to read when a change you are planning touches something a decision record already settles.

## pages

- [architecture](architecture.md): how one source root becomes a configuration for each runtime, stage by stage.
- [decisions](decisions/README.md): agentrc's own decision records, one per choice that shaped the code.
