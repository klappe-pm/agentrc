# 2026-10-10-the-stratarc-name-passed-its-checks-with-two-caveats

## status

accepted, 2026-10-10. Confirms [rename to stratarc](2026-10-09-rename-to-stratarc.md), which left trademark registers unchecked.

## context

The rename record chose `stratarc` after a registry check and left the trademark registers and several platforms unchecked. A follow-up check queried the United States trademark search for `stratarc` and the near forms `stratarcs`, `stratarch` and `strata` with `arc`, searched for products, domains and organizations with the name, and looked for other tools that use a `.stratarc` directory.

## decision

The name stays. The United States search found no mark for it, and the nearest live marks are one letter off and cover roofing project software, business consulting and design. No package or organization with the name exists on PyPI, npm, crates.io, RubyGems, Homebrew, Flathub, Chocolatey, winget, the Go module index, the Arch user repository, Docker Hub or the Snap Store. Two caveats are recorded. A web application for strategic planning is live at stratarc.app with a 2026 copyright line, no named operator and no registered mark. It serves a different field, but it is the one real neighbor, so the README describes this tool as an agent configuration source to keep the two apart. The European and international trademark databases could not be queried, and any common-law rights of the planning application's operator are unknown. Registering the package name on PyPI is recommended and is left to the maintainer, because publishing to a registry is an outward step this work does not take on its own.

## alternatives

Renaming again was rejected because the checks found no conflict that a rename would remove, and a second rename would repeat the cost of the first. Waiting for the European and international searches was rejected because their public search tools offer no interface that can be queried from a script, so waiting would add no information. Choosing the second and third candidates from the original name check was rejected for the same reason as a rename.

## consequences

The name can be used in the first release. The caveats stay on the record: if the operator of the planning application objects, or a European or international mark appears, a new record supersedes this one. Anyone who files a trademark application should run the European and international searches by hand first.
