# 2026-10-09-static-docs-site-built-from-the-repo

## status

accepted

## context

The documentation lives as Markdown in `docs/` and `developer-docs/`. A command reference and an error catalog written by hand would drift from the code, and a site that needs a framework or a script runtime would add dependencies to a package that has none. Readers also arrive on phones and in dark mode, and a first-load page must be light. The builder is [scripts/docs/build_site.py](../../../scripts/docs/build_site.py) and its templates are under [scripts/docs/templates](../../../scripts/docs/templates).

## decision

The site is generated by a standard library script that is a development tool and is not shipped in the wheel. It reads `docs/` and `developer-docs/`, emits no JavaScript, follows the reader's light or dark setting and works at phone width. The command reference and the error catalog are generated from the code and committed under `docs/reference/generated/`, and `build_site.py --check` exits 6 when a committed page differs from the code. Error pages are anchored by message id, and the static load page stays under 50 KB with no animation. CI builds the site and runs the check but does not deploy it. The landing page leads with a real captured `config explain` run against the bundled example.

## alternatives

- A documentation framework or static site generator. It would bring themes and search, but it adds a dependency chain and often scripts, which conflicts with the zero-dependency, no-JavaScript goal.
- Hand-written reference pages. They are easy to start and certain to drift, which the `--check` mode exists to prevent.
- Deploy from CI on every merge. Deciding where the site is hosted is a separate choice, so CI proves the build and the maintainer publishes.
- A hand-written demo on the landing page. A captured run cannot claim output the engine does not produce.

## consequences

- A change to a command, flag or message makes CI fail until the generated pages are rewritten with `--write-generated`.
- The site has no search and a plain left navigation, by design.
- The size and no-animation limits of the load page are enforced by [tests/test_docs_site.py](../../../tests/test_docs_site.py).
- The builder is outside the installed package, so contributors run it from a checkout.
- Publishing remains a manual step until a later record decides otherwise.
