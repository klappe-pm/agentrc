# agents

`notes-cli` is a command-line notes tool written in Python. Notes are stored as plain files in a directory named by the `NOTES_HOME` environment variable, with a small SQLite index beside them in `notes.db`.

## layout

- `notes_cli/`: the package. `storage.py` reads and writes notes, `search.py` queries the index, `cli.py` holds the commands.
- `tests/`: the pytest suite.
- `changelog.md`: user-facing changes, newest under `unreleased`.

## working-in-this-project

Run `python3 -m pytest -q` before proposing a commit. Never open or edit `notes.db` directly; use the commands in `notes_cli/cli.py`. A change to the on-disk format follows the `storage-format-is-versioned` rule.

### never-commit-local-databases

Tier: global.

Never stage or commit a local database or the files SQLite keeps beside it: `*.db`, `*.sqlite`, `*.sqlite3` and their `-journal`, `-wal` and `-shm` companions. If one is already tracked, stop and report it instead of rewriting history.

### conventional-commit-messages

Tier: common.

Write each commit subject as `type(scope): summary`, using `feat`, `fix`, `docs`, `refactor`, `test` or `chore` as the type. Keep the summary lowercase, imperative and under 72 characters. Put the reason for the change in the body, not the subject.

Full rule: `$HOME/stratarc-source/rules/conventional-commit-messages.md`

### tests-use-a-temporary-directory

Tier: project.

A test that reads or writes notes runs against a temporary directory and never against the real notes directory. Point `NOTES_HOME` at the test's temporary path before the code under test runs.

Full rule: `$HOME/stratarc-source/rules/tests-use-a-temporary-directory.md`
