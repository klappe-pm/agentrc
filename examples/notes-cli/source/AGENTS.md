# agents

This source root holds the instructions, rules, hooks, skills, commands, agents and permissions that `stratarc sync` compiles into Claude Code, Codex, Gemini CLI, Cursor and OpenCode. Runtime directories such as `~/.claude` are generated output; edit the files here, not the deployed copies.

## source-and-output-boundary

Edit only this source root. A later `stratarc sync` overwrites every runtime target named in `stratarc.toml`, so a change made directly in a runtime directory is lost.

## editing-and-sync

Hook registration belongs in `hooks/hooks.json`. Permissions belong in `permissions.json`. External components belong in `components.json`. Project-local configuration belongs in `projects-root/<project>/`. After an edit, run `stratarc diff` to preview the change and `stratarc sync` to deploy it.

## working-style

Prefer small, reviewable changes. Run the project's tests before proposing a commit, and say which command you ran. When a task leaves a detail unstated, name the assumption you are making instead of guessing silently.

## authority-order

Inside a project, apply that project's validators and CI first, its own instruction files second, and this source root's configuration third.
