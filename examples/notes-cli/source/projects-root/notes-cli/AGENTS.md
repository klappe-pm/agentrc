# agents

`notes-cli` is a command-line notes tool written in Python. Notes are stored as plain files in a directory named by the `NOTES_HOME` environment variable, with a small SQLite index beside them in `notes.db`.

## layout

- `notes_cli/`: the package. `storage.py` reads and writes notes, `search.py` queries the index, `cli.py` holds the commands.
- `tests/`: the pytest suite.
- `changelog.md`: user-facing changes, newest under `unreleased`.

## working-in-this-project

Run `python3 -m pytest -q` before proposing a commit. Never open or edit `notes.db` directly; use the commands in `notes_cli/cli.py`. A change to the on-disk format follows the `storage-format-is-versioned` rule.
