# state-assumptions

## binding

Before acting on a task that leaves a material detail unstated, name the assumption you are making in one sentence. If the assumption would change the outcome and cannot be checked from the files at hand, ask instead of assuming.

## examples

- A request to "add a test" in a repository with two test frameworks: state which one you are using and why.
- A request to "rename the function" with callers in other packages: state whether you are updating those callers.
